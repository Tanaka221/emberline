EMBERLINE is a round-based tactical FPS in three.js: single-player against 4 bots on the original Foundry Yard map, with rounds, an economy and buy menu, bomb plant and defuse, headshot damage, recoil and spread, and a full HUD.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
